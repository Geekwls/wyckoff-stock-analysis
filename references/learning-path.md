# 威科夫理论渐进式学习路径

## 学习路线图总览

```
Level 1 (初级) → Level 2 (中级) → Level 3 (高级) → Level 4 (专家)
   1-2个月        2-4个月         4-6个月         持续精进
```

---

## Level 1: 威科夫理论入门（1-2个月）

### 学习目标

完成Level 1后，你应该能够：
- ✅ 理解威科夫理论的核心概念
- ✅ 识别积累和分布的基本阶段
- ✅ 看懂成交量与价格的关系
- ✅ 在图表上找到PS, CL, AR, ST等关键点
- ✅ 知道什么是Spring和Upthrust

---

### 第1周：基础概念

#### 必学内容
1. **威科夫三大定律**
   - 供求定律
   - 因果定律
   - 努力vs结果定律

2. **市场周期四个阶段**
   - Accumulation（积累期）
   - Markup（上涨期）
   - Distribution（分布期）
   - Markdown（下跌期）

#### 学习方法
- 📖 阅读：SKILL.md的前1/3
- 📺 视频：搜索"Wyckoff method basics"（YouTube/bilibili）
- 📝 笔记：用自己的话总结三大定律

#### 自我测试
```
问题1: 如果价格上涨但成交量下降，这意味着什么？
答案: 弱势上涨，需求不足，可能反转

问题2: 威科夫市场周期的正确顺序是什么？
答案: Accumulation → Markup → Distribution → Markdown

问题3: "因"和"果"在威科夫理论中指什么？
答案: 因=积累/分布区间，果=随后的价格趋势
```

---

### 第2周：积累期详解

#### 必学内容
1. **积累期的5个阶段**
   - Phase A: PS, CL, AR, ST
   - Phase B: 横盘整理
   - Phase C: Spring（震仓）
   - Phase D: SOS, LPS
   - Phase E: 上涨趋势

2. **关键事件识别**
   - PS (Preliminary Support)
   - CL (Climax)
   - AR (Automatic Rally)
   - ST (Secondary Test)

#### 学习方法
- 📊 练习：在历史图表上找积累期
- 🎯 重点：识别PS, CL, AR, ST四个事件
- 📝 作业：找到5个积累期的实际案例

#### 实战练习
```
练习任务：
1. 打开股票K线图（推荐用TradingView或同花顺）
2. 寻找明显下跌后的横盘区间
3. 在该区间标记：
   - 最低点（可能是CL）
   - 第一次反弹（可能是AR）
   - 再次测试低点（可能是ST）
4. 记录成交量在这些点位的变化
```

---

### 第3周：分布期详解

#### 必学内容
1. **分布期的5个阶段**
   - Phase A: PSY, CL, AR, ST
   - Phase B: 横盘整理
   - Phase C: Upthrust（假突破）
   - Phase D: SOW, LPSY
   - Phase E: 下跌趋势

2. **与积累期的对比**
   - 相似点：都有5个阶段，都有横盘
   - 不同点：位置不同（高位vs低位），方向相反

#### 学习方法
- 📊 练习：在历史图表上找分布期
- 🎯 重点：区分积累期和分布期
- 📝 作业：找到5个分布期的实际案例

#### 对比练习
```
对比任务：
同时观察两支股票：
股票A: 下跌后横盘（可能是积累）
股票B: 上涨后横盘（可能是分布）

思考：
1. 它们的位置有什么不同？
2. 成交量特征有什么不同？
3. 后续走势有什么不同？
```

---

### 第4周：成交量分析基础

#### 必学内容
1. **成交量与价格的关系**
   - 价涨量增：强势
   - 价涨量减：弱势
   - 价跌量增：强势下跌
   - 价跌量减：弱势下跌

2. **成交量形态**
   - 放量（Volume Expansion）
   - 缩量（Volume Contraction）
   - 极量（Climactic Volume）

#### 学习方法
- 📊 练习：观察成交量柱状图
- 🎯 重点：理解"努力vs结果"
- 📝 作业：分析10个成交量案例

#### 实战练习
```
成交量观察任务：
1. 找一个明显上涨的股票
2. 观察上涨过程中成交量如何变化
3. 找出"价涨量增"和"价涨量减"的时刻
4. 记录哪个时刻后续继续上涨，哪个反转

5. 找一个明显下跌的股票
6. 重复以上观察
```

### 第5-6周：Spring和Upthrust

#### 必学内容
1. **Spring（震仓）**
   - 定义：跌破支撑后快速收回
   - 意义：最后一跌，清除弱者
   - 确认：1-3天内回到支撑上方

2. **Upthrust（假突破）**
   - 定义：突破阻力后快速回落
   - 意义：最后一涨，吸引散户
   - 确认：1-3天内回到阻力下方

#### 学习方法
- 📊 练习：在图表上找Spring和Upthrust
- 🎯 重点：区分真假突破
- 📝 作业：找到各5个案例

#### 识别练习
```
Spring识别任务：
1. 寻找横盘区间的股票
2. 观察是否有短暂跌破支撑
3. 判断：
   - 几天内收回？
   - 成交量如何？
   - 后续如何发展？
4. 分类：真Spring vs 假跌破（继续下跌）

Upthrust识别任务：
1. 寻找高位横盘的股票
2. 观察是否有短暂突破阻力
3. 判断：
   - 几天内回落？
   - 成交量如何？
   - 后续如何发展？
4. 分类：真Upthrust vs 真突破（继续上涨）
```

### 第1-2周：威科夫5步骤方法

#### 必学内容
1. **Step 1: 确定当前位置和趋势**
2. **Step 2: 判断相对强度**
3. **Step 3: 找到与趋势一致的股票**
4. **Step 4: 判断准备程度（因果）**
5. **Step 5: 把握交易时机**

#### 学习方法
- 📖 阅读：SKILL.md中"5步骤"章节
- 📊 练习：用5步骤分析10支股票
- 📝 作业：完成5步骤分析模板

#### 实战模板
```
威科夫5步骤分析模板：

股票代码：________
分析日期：________

Step 1 - 当前位置：
□ 积累期 Phase A/B/C/D/E
□ 上涨期
□ 分布期 Phase A/B/C/D/E
□ 下跌期
理由：______________________

Step 2 - 相对强度：

□ 弱于大盘

Step 3 - 趋势一致性：
□ 与大盘趋势一致
□ 与大盘趋势相反
□ 大盘震荡，个股独立

目标价格：____元
风险回报比：____:____
```

### 第3-4周：相对强度分析

#### 必学内容
1. **相对强度（Relative Strength）定义**
2. **如何绘制RS线**
3. **RS与威科夫阶段的关系**

#### 学习方法
- 📊 练习：绘制RS线
- 🎯 重点：找出强于大盘的股票
- 📝 作业：筛选20支股票的RS排名

#### 实战练习
```
相对强度分析任务：

1. 选择一个市场指数（如上证指数、标普500）
2. 选择10支感兴趣的股票
3. 计算相对强度：
   - 3个月前价格 vs 现在
   - 股票涨跌幅 / 指数涨跌幅
   - 结果>1 = 强，<1 = 弱
4. 排序并分类
5. 结合威科夫阶段分析：
   - 强股票 + 积累期 = 重点关注
   - 弱股票 + 分布期 = 避免或做空
```

### 第5-6周：Re-accumulation和Re-distribution

#### 必学内容
1. **Re-accumulation（再积累）特征**
2. **Re-distribution（再分布）特征**
3. **如何区分初次和再次**

#### 学习方法
- 📊 练习：识别历史图表中的再积累/再分布
- 🎯 重点：区分Major和Re版本
- 📝 作业：找到各5个案例

#### 识别要点
```
Re-accumulation vs Major Accumulation：

对比维度：
- 位置：上涨中途 vs 长期底部
- 时间：3-6周 vs 8-20周
- 成交量：适中 vs 可能很大
- 后续：继续上涨 vs 新的上涨趋势

Re-distribution vs Major Distribution：

对比维度：
- 位置：下跌中途 vs 长期顶部
- 时间：3-6周 vs 8-20周
- 成交量：适中 vs 可能很大
- 后续：继续下跌 vs 新的下跌趋势
```

#### 模拟交易规则
```
Level 2 模拟交易要求：

1. 资金：假设100,000元
2. 单笔风险：不超过2%（2,000元）
3. 交易次数：至少10笔
4. 记录内容：
   - 入场理由（威科夫依据）
```

#### 分析流程
```
多时间框架分析流程：

第一步：周线分析
- 确定大趋势
- 识别主要阶段
- 判断长期方向

第二步：日线分析
- 识别威科夫形态
- 定位当前阶段
- 找到关键事件

第三步：小时线分析
- 精确入场点位
- 优化入场价格
- 设置精确止损

第四步：一致性检查
- 三个时间框架方向是否一致？

- 如果冲突 → 等待或放弃
```

## Level 3: 自动化分析与系统化筛选（4-6个月）

### 学习目标

完成Level 3后，你应该能够：
- ✅ **系统化筛选**：利用 `ScreenerService` 在全市场（A股/美股）中自动定位潜在机会。
- ✅ **回测验证**：使用 `BacktestEngine` 对特定形态的历史表现进行量化验证。
- ✅ **识别复杂变体**：处理 Spring 失败、SOS 失败等复杂形态。
- ✅ **构建量化工作流**：将 AI Agent (MCP Server) 接入日常复盘流程。

### 第1-2周：系统化扫描实战
1. **掌握 ScreenerService**
   - 使用 `quick_scan` 进行板块级快速扫描。
   - 使用 `deep_screen` 进行深度阶段过滤（如：只看处于 Accumulation Phase C 的股票）。
2. **构建自己的 Stock Pools**
   - 在 `wyckoff_utils.py` 中定义关注的板块。

### 第3-4周：量化回测与胜率分析
1. **使用 BacktestEngine**
   - 对识别出的信号进行历史回测。
   - 分析特定行业/市值下的威科夫信号成功率。
2. **阈值调优**
   - 根据回测结果调整检测阈值（如成交量倍数、突破幅度）。

### 第5-8周：AI Agent 协同复盘
1. **集成 MCP Server**
   - 在 Claude Desktop 或 Cursor 中配置 `mcp_server.py`。
   - 练习通过对话式指令进行市场全景扫描。
2. **深度报告生成**
   - 利用 `ReportGenerator` 生成结构化分析，并与手动分析进行对比。

## 常见学习困难

### 困难1: 理论理解了但实战不会

**解决方案**：
- 多看历史案例
- 用模拟交易练习
- 找导师或学习小组
- 不要急于用真钱

### 困难2: 形态识别不准确

**解决方案**：
- 先看明显的形态
- 不明显的放弃
- 多时间框架确认
- 不确定性太大就放弃

### 困难3: 执行纪律不够

**解决方案**：
- 写下交易计划
- 设置自动止损
- 找 accountability partner
- 定期复盘和反思

### 困难4: 连续亏损后失去信心

**解决方案**：
- 接受亏损是正常的
- 减少仓位规模
- 回到模拟交易
- 重新学习基础

## 最后的建议

### 学习心态

1. **耐心**：不要急于求成
2. **谦虚**：市场永远是对的
3. **纪律**：执行比分析更重要
4. **持续**：学习是终身的

### 学习原则

1. **理论 + 实践**：不要只学不做
2. **模拟 + 实盘**：先模拟后实盘
3. **小资金 + 大资金**：先小后大
4. **复盘 + 改进**：每周都要复盘

### 避免的错误

1. 不要跳过Level直接学高级
2. 不要模拟没盈利就做实盘
3. 不要连续亏损后加大仓位
4. 不要停止学习
