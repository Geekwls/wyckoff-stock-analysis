# 基于孟洪涛《新威科夫操盘法》的实战交易指南

> 本指南整合了孟洪涛书中290页的核心实战经验，提供可直接执行的交易策略

---

## 快速决策流程图

```
开始
  ↓
第一步：市场环境判断（1分钟）
  ├── 大盘趋势：牛/熊/震荡？
  ├── 个股阶段：Accumulation/Distribution？
  └── 相对强度：强于/弱于大盘？
  ↓
第二步：形态扫描（3分钟）
  ├── Spring（震仓）：5个必要条件？
  ├── JOC（跃过小溪）：长阳线+大成交量？
  ├── LPS（最后支撑）：缩量回调？
  └── VSA信号：无供应/无需求？
  ↓
第三步：信号确认（2分钟）
  ├── 成交量是否配合？
  ├── 多时间框架是否一致？
  └── 因果测算是否合理？
  ↓
第四步：入场决策（1分钟）
  ├── ✅ 所有条件满足 → 入场
  ├── ⚠️ 部分条件满足 → 观望
  └── ❌ 条件不满足 → 放弃
  ↓
第五步：风险管理（立即）
  ├── 设置止损：关键位下方
  ├── 计算仓位：信号质量×市场环境
  └── 设置目标：因果测算
```

## 一、Spring（震仓）实战策略

### 检测清单（5个必要条件）

```
□ 跌破幅度：1-3%（2%最佳）
□ 收回时间：1-3天（2天最佳）
□ 收回确认：收盘价站稳支撑位上方
□ 成交量：收回时 > 跌破时
□ 收盘位置：日内高位70%以上
```

### 交易执行表

| 步骤 | 操作 | 具体要求 | 风险控制 |
|------|------|----------|----------|
| **1. 等待Spring** | 观望 | 不要提前入场 | 保持耐心 |
| **2. Spring确认** | 观察 | 5个条件全满足 | 不满足就放弃 |
| **3. 等待LPS** | 观察 | 缩量回调到支撑位 | 不要急于买入 |
| **4. LPS确认** | 入场 | 成交量极度萎缩 | 立即设置止损 |
| **5. 止损设置** | 风险控制 | Spring低点下方5% | 坚决执行 |
| **6. 目标设置** | 获利计划 | 因果测算1.618倍 | 分批止盈 |

### 常见错误处理

| 错误 | 表现 | 正确做法 |
|------|------|----------|
| 过早入场 | Spring未确认就买入 | 等待收盘价站稳支撑位 |
| 忽视成交量 | 收回时成交量没放大 | 必须等待成交量配合 |
| 不设止损 | "应该会涨回来" | 每笔交易必须设止损 |
| 止损移大 | 跌破后把止损移大 | 坚决执行原始止损 |

## 二、JOC（跃过小溪）实战策略

### 检测清单

```
□ 突破确认：长阳线突破阻力位（涨幅>3%）
□ 突破量能：成交量>1.5倍均量
□ 收盘位置：日内高位75%以上
□ 回测确认：缩量回落不破阻力位
```

### 交易执行表

| 步骤 | 操作 | 具体要求 | 风险控制 |
|------|------|----------|----------|
| **1. 等待JOC** | 观察 | 长阳线+大成交量 | 不要追高 |
| **2. JOC确认** | 观察 | 收盘在高位 | 确认突破有效 |
| **3. 等待回测** | 观察 | 缩量回落到阻力位 | 最佳入场点 |
| **4. 回测买入** | 入场 | 成交量萎缩 | 立即设置止损 |
| **5. 止损设置** | 风险控制 | JOC起涨点下方 | 坚决执行 |
| **6. 目标设置** | 获利计划 | 因果测算1.618-2.618倍 | 分批止盈 |

### JOC vs SOS的选择

```
JOC优先的情况：
├── 突破力度强（长阳线>3%）
├── 成交量大（>2倍均量）
├── 收盘位置高（>80%）
└── 有回测确认

SOS可以接受的情况：
├── 突破力度中等（2-3%）
├── 成交量放大（>1.5倍）
├── 收盘位置尚可（>70%）
└── 后续确认跟进

实战建议：优先交易JOC，质量更高
```

## 三、VSA微观分析实战

### No Supply（无供应）识别与交易

```
识别特征：
├── 出现在上涨回调中
├── 极小实体（波动<0.5%）
├── 收在中高位（>50%）
└── 成交量<均量60%

交易信号：✅ 强烈买入
入场时机：确认后立即入场
止损位置：该日最低点下方
目标位置：前高或因果测算
```

### No Demand（无需求）识别与交易

```
识别特征：
├── 出现在下跌反弹中
├── 极小实体
├── 收盘位置不限
└── 成交量<均量60%

交易信号：⚠️ 做空或减仓（A股）
操作建议：逢高减仓
```

### Stopping Volume（停止行为）识别

```
识别特征：
├── 出现在下跌末期
├── 大成交量（>1.5倍均量）
├── 价格止跌（窄幅波动）
└── 可能有长下影线

交易信号：⏳ 可能筑底
操作建议：等待Spring确认
```

```
止盈策略：

```

```

入场策略：
├── 更严格的入场条件

├── Spring质量必须很高
└── 优先交易强势股

├── 基础仓位：20-30%

止盈策略：

```

```
├── 只交易最清晰形态

仓位管理：
├── 基础仓位：20-30%
```

## 五、仓位管理系统

### 信号质量评分

```python
def calculate_signal_quality():
    """
    信号质量评分（0-10分）
    """
    score = 0

    # 1. 形态完整性（4分）
    if Spring_5条件全满足:
        score += 4
    elif JOC_4条件全满足:
        score += 3.5
    elif SOS确认:
        score += 2

    # 2. 成交量配合（3分）
    if 成交量>2倍均量:
        score += 3
    elif 成交量>1.5倍均量:
        score += 2
    elif 成交量>1.2倍均量:
        score += 1

    # 3. 市场环境（3分）
    if 牛市 and 个股积累:
        score += 3
    elif 震荡市 and 个股积累:
        score += 1.5
    elif 熊市:
        score += 0

    return score
```

### 基于评分的仓位

| 信号质量 | 保守型 | 稳健型 | 激进型 |
|----------|--------|--------|--------|
| 8-10分 | 30% | 50% | 70% |
| 5-7分 | 20% | 30% | 50% |
| 3-4分 | 观望 | 20% | 30% |
| 0-2分 | 观望 | 观望 | 观望 |

### 分批建仓表

| 批次 | 时机 | 仓位 | 止损 | 目标 |
|------|------|------|------|------|
| **第一批** | LPS确认 | 30% | Spring下方 | 因果50% |
| **第二批** | SOS确认 | 50% | LPS下方 | 因果100% |
| **第三批** | 趋势确认 | 20% | 移动止损 | 因果150% |

## 六、止损止盈系统

### ATR动态止损

```python
# 计算ATR止损
ATR = 计算ATR(14日)

# 做多止损
止损价 = 入场价 - (ATR × 2)

# 做空止损
止损价 = 入场价 + (ATR × 2)

# 优点：根据波动率动态调整
```

### 移动止损规则

```
初始止损：关键位下方
  ↓
盈利5% → 移动到入场价（保本）
  ↓
盈利10% → 移动到盈利5%位置
  ↓
盈利15% → 移动到盈利10%位置
  ↓
依此类推...
```

### 分批止盈策略

```
达到目标50% → 减仓30%
  ↓
达到目标70% → 再减仓30%
  ↓
达到目标100% → 再减仓30%
  ↓
剩余10% → 移动止损持有
```

## 九、常见问题解答

### Q1: Spring跌破太深怎么办？

```
A: 这不是真Spring，放弃该机会。
   真Spring的跌破幅度应该在1-3%之间。
   如果跌破超过5%，可能是趋势反转。
```

### Q2: LPS没出现怎么办？

```
A: 继续等待或放弃该机会。
   不要在没有LPS确认的情况下入场。
   LPS是最佳入场点，不是唯一入场点，
   但必须是缩量确认的支撑位。
```

### Q3: 止损被触发后怎么办？

```
A: 立即止损，不要犹豫。
   分析触发原因：
   - 假信号？→ 继续等待下一个机会
   - 止损设置太紧？→ 下次放宽到合理位置
   - 入场太早？→ 下次等待完整信号
   然后继续等待下一个高质量信号。
```

### Q4: 可以提前加仓吗？

```
A: 不建议。
   严格按照分批建仓策略：
   第一批：LPS确认后（30%）
   第二批：SOS确认后（50%）
   第三批：趋势确认后（20%）
   不要提前加仓，不要在亏损时加仓。
```

### Q5: 牛市和熊市策略差异大吗？

```
A: 很大。
   牛市：可以更早入场，仓位更大，目标更高
   熊市：必须等待确认，仓位更小，快进快出
   震荡市：减少交易频率，只做最清晰形态

   最重要的：根据市场环境调整策略
```
