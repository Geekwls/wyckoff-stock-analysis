# 威科夫策略优化指南

## 一、信号过滤优化（减少假信号）

### 1.1 Spring 信号过滤

#### 原始条件
- 跌破支撑位
- 3天内收回

#### 优化后条件（满足所有条件才确认）

```
必要条件：
├── 1. 跌破幅度：1-3%（不能太深）
├── 2. 收回时间：1-3天（根据波动率调整）
├── 3. 收回确认：收盘价站稳支撑位上方
├── 4. 成交量：收回时成交量 > 跌破时成交量
└── 5. 收盘位置：收回日收盘价在日内高位70%以上

加分条件（满足越多越好）：
├── 跌破时缩量（恐慌盘不多）
├── 收回时放量（需求强劲）
├── 随后出现缩量回调（LPS确认）
└── 大盘处于积累或上涨阶段
```

#### 动态时间窗口

```python
# 根据ATR调整确认时间
atr = calculate_atr(period=14)
daily_range = atr / current_price

if daily_range < 0.02:  # 低波动股票
    confirmation_days = 3
elif daily_range < 0.04:  # 中等波动
    confirmation_days = 2
else:  # 高波动
    confirmation_days = 1
```

### 1.2 Upthrust 信号过滤

#### 优化后条件

```
必要条件：
├── 1. 突破幅度：1-3%（不能太高）
├── 2. 回落时间：1-3天
├── 3. 回落确认：收盘价跌回阻力位下方
├── 4. 成交量：回落时成交量 > 突破时成交量
└── 5. 收盘位置：回落日收盘价在日内低位70%以下

加分条件：
├── 突破时放量（吸引散户）
├── 回落时放量（主力出货）
├── 上影线长（卖压明显）
└── 大盘处于分布或下跌阶段
```

### 1.3 SOS/SOW 信号过滤

#### 优化后条件

```
SOS（强势信号）必要条件：
├── 1. 涨幅：> 3%（大盘股）或 > 5%（小盘股）
├── 2. 成交量：> 1.5倍20日均量
├── 3. 收盘位置：收盘价在日内高位70%以上
├── 4. 突破确认：突破前期阻力位
└── 5. 后续确认：随后2-3天不跌破突破位

SOW（弱势信号）必要条件：
├── 1. 跌幅：> 3%（大盘股）或 > 5%（小盘股）
├── 2. 成交量：> 1.5倍20日均量
├── 3. 收盘位置：收盘价在日内低位70%以下
├── 4. 跌破确认：跌破前期支撑位
└── 5. 后续确认：随后2-3天不突破跌破位
```

## 二、多时间框架联动优化

### 2.1 时间框架定义

| 时间框架 | 用途 | 分析内容 |
|----------|------|----------|
| 周线/月线 | 大趋势方向 | 确定主阶段（积累/上涨/分布/下跌） |
| 日线 | 形态识别 | 识别威科夫形态和关键事件 |
| 小时线 | 入场时机 | 精确LPS/LPSY入场点位 |

### 2.2 联动规则

```
规则1：方向一致性
├── 周线上涨 + 日线积累 → 可以做多
├── 周线下跌 + 日线分布 → 可以做空
├── 周线上涨 + 日线分布 → 观望（可能Re-accumulation）
└── 周线下跌 + 日线积累 → 观望（可能Re-distribution）

规则2：阶段确认
├── 周线Phase D + 日线SOS → 确认做多
├── 周线Phase D + 日线SOW → 确认做空
├── 周线Phase B + 日线Phase C → 等待
└── 周线Phase E + 日线Phase A → 趋势可能反转

规则3：冲突处理
├── 时间框架冲突 → 观望
├── 信号不一致 → 等待更多确认
└── 不确定 → 放弃交易
```

### 2.3 多时间框架检查清单

```
入场前必须检查：

□ 周线趋势方向明确
□ 日线形态清晰
□ 小时线有精确入场点
□ 三个时间框架方向一致
□ 无明显冲突信号
```

## 三、量化标准细化

### 3.1 成交量标准（动态调整）

#### 基础标准

| 信号 | 标准成交量 | 调整因素 |
|------|------------|----------|
| CL | 3-5x 均量 | 市场恐慌程度 |
| Spring反转 | 1.5-2x 跌破量 | 波动率 |
| SOS/SOW | 1.5-2.5x 均量 | 股票类型 |
| LPS/LPSY | 40-60% SOS量 | 回调幅度 |

#### 动态调整公式

```python
# 根据股票类型调整
def get_volume_threshold(stock_type, base_threshold):
    adjustments = {
        'large_cap': 0.8,    # 大盘股要求低一些
        'mid_cap': 1.0,      # 中盘股标准
        'small_cap': 1.3,    # 小盘股要求高一些
        'high_volatility': 1.2  # 高波动股要求更高
    }
    return base_threshold * adjustments.get(stock_type, 1.0)

# 根据市场环境调整
def adjust_for_market环境(threshold, market_env):
    if market_env == 'bull':
        return threshold * 0.9  # 牛市要求低一些
    elif market_env == 'bear':
        return threshold * 1.2  # 熊市要求更高
    else:
        return threshold
```

## 四、市场环境适应

### 4.1 市场环境判断

```python
def判断市场环境(index_data):
    """
    基于大盘指数判断市场环境
    """
    ma20 = index_data['close'].rolling(20).mean()
    ma50 = index_data['close'].rolling(50).mean()
    ma200 = index_data['close'].rolling(200).mean()
    
    current = index_data['close'].iloc[-1]
    
    if current > ma20 > ma50 > ma200:
        return 'strong_bull'  # 强势牛市
    elif current > ma50 and ma50 > ma200:
        return 'bull'  # 牛市
    elif current < ma20 < ma50 < ma200:
        return 'strong_bear'  # 强势熊市
    elif current < ma50 and ma50 < ma200:
        return 'bear'  # 熊市
    else:
        return 'sideways'  # 震荡
```

### 4.2 不同环境的策略调整

#### 牛市策略

```
入场条件：
- 接受较高的入场价格
- 允许较宽的止损（3-5%）
- 可以更早入场（Phase C末端）

仓位管理：
- 基础仓位：50-70%
- 加仓条件：SOS确认后
- 最大仓位：80%

止盈策略：
- 目标位：因果测算的120-150%
- 分批止盈：达到目标50%先减仓30%
```

#### 熊市策略

```
入场条件：
- 更严格的入场条件
- 必须等待LPS确认
- 止损必须紧凑（2-3%）

仓位管理：
- 基础仓位：20-30%
- 不加仓
- 总仓位不超过40%

止盈策略：
- 目标位：因果测算的80-100%
- 快速止盈：达到目标立即减仓50%
```

#### 震荡市策略

```
入场条件：
- 减少交易频率
- 只交易最清晰的形态
- 等待多重确认

仓位管理：
- 基础仓位：20-30%
- 单笔风险：<1%

止盈策略：
- 缩小目标：因果测算的50-70%
- 快进快出
```

### 4.3 环境适应检查清单

```
交易前检查：

□ 判断当前市场环境
□ 调整入场条件
□ 调整仓位大小
□ 调整止损止盈
□ 记录环境判断依据
```

```python
def判断板块阶段板块股票列表):
    """
    分析板块内多只股票，判断整体阶段
    """
    phases = []
    for stock in 板块股票列表:
        phase = identify_phase(stock)
        phases.append(phase)
    
    # 统计各阶段股票数量
    accumulation_count = phases.count('Accumulation')
    markup_count = phases.count('Markup')
    distribution_count = phases.count('Distribution')
    markdown_count = phases.count('Markdown')
    
    # 判断板块整体阶段
    if accumulation_count > len(phases) * 0.5:
        return '板块积累期'
    elif markup_count > len(phases) * 0.5:
        return '板块上涨期'
    elif distribution_count > len(phases) * 0.5:
        return '板块分布期'
    elif markdown_count > len(phases) * 0.5:
        return '板块下跌期'
    else:
        return '板块分化'
```

### 5.3 龙头股识别

```
龙头股特征：
├── 1. 率先完成积累（比板块其他股票早）

├── 3. 相对强度最高（强于板块其他股票）
├── 4. 基本面优秀（业绩、行业地位）
└── 5. 资金持续流入

交易策略：
├── 优先买入龙头股
├── 龙头股仓位可以更大
├── 龙头股止损可以更宽
└── 龙头股目标可以更高
```

### 5.4 板块轮动规律

```
牛市轮动顺序：
├── 1. 金融板块（银行、券商）
├── 2. 周期板块（地产、建材）
├── 3. 消费板块（白酒、食品）

├── 1. 题材板块先跌
├── 2. 科技板块跟跌
├── 3. 消费板块补跌
├── 4. 周期板块下跌
└── 5. 金融板块最后跌

交易策略：
├── 牛市：跟随轮动顺序买入
├── 熊市：避免买入，等待底部
```

## 六、仓位管理优化

### 6.1 基于信号强度的仓位

```python
def calculate_position_size信号强度, 市场环境, 账户风险):
    """
    根据信号强度动态计算仓位
    """
    base_position = 0.3  # 基础仓位30%
    
    # 信号强度调整
    if 信号强度 >= 4:  # 多个信号确认
        position_multiplier = 1.5
    elif 信号强度 >= 2:
        position_multiplier = 1.0
    else:
        position_multiplier = 0.5
    
    # 市场环境调整
    if 市场环境 == 'bull':
        env_multiplier = 1.3
    elif 市场环境 == 'bear':
        env_multiplier = 0.7
    else:
        env_multiplier = 1.0
    
    # 计算最终仓位
    position = base_position * position_multiplier * env_multiplier
    
    # 限制最大仓位
    return min(position, 0.8)
```

```
第一批（试探仓）：

第二批（主仓位）：
```

## 七、止损止盈优化

### 7.1 ATR止损

```python
def calculate_atr_stop(entry_price, atr, multiplier=2):
    """
    基于ATR的动态止损
    """
    stop距离 = atr * multiplier
    return entry_price - stop距离

# 示例
# 入场价：100元
# ATR：2元
# 止损：100 - 2*2 = 96元（4%止损）
```

### 7.2 移动止损

```
移动止损规则：
├── 初始止损：Spring下方或ATR止损
├── 第一次移动：盈利5%后，止损移到入场价
├── 第二次移动：盈利10%后，止损移到盈利5%位置
├── 第三次移动：盈利15%后，止损移到盈利10%位置
└── 依此类推

公式：
新止损 = 最高价 - (最高价 * 移动比例)
```

### 7.3 时间止损

```
时间止损规则：
├── 入场后N天未达目标 → 减仓50%
├── 入场后2N天仍未达目标 → 清仓
└── N根据时间框架决定

示例：
├── 日线交易：N=10天
├── 周线交易：N=5周
└── 月线交易：N=3月
```

### 7.4 分批止盈

```
分批止盈策略：
├── 达到目标50% → 减仓30%
├── 达到目标70% → 再减仓30%
├── 达到目标100% → 减仓30%
└── 剩余10% → 移动止损持有

示例（目标10元）：
├── 盈利5元时 → 卖出30%
├── 盈利7元时 → 再卖出30%
├── 盈利10元时 → 再卖出30%
└── 剩余10% → 移动止损
```

### 7.5 止损止盈检查清单

```
入场前必须确定：

□ 初始止损位置
□ ATR止损计算
□ 目标价位（因果测算）
□ 分批止盈计划
□ 时间止损期限
□ 移动止损规则
```

```
假Spring特征：
├── 跌破幅度太深（>5%）
```

## 十、总结

### 优化核心要点

1. **信号过滤**：多条件确认，减少假信号
2. **多时间框架**：方向一致才交易
3. **量化标准**：动态调整，区分股票类型
4. **市场适应**：牛熊市不同策略
5. **板块轮动**：A股特有，跟随资金
6. **仓位管理**：基于信号强度动态调整
7. **止损止盈**：ATR止损、移动止损、分批止盈

### 执行原则

```
1. 纪律第一：严格执行交易计划
2. 风险优先：保护本金最重要
3. 持续改进：记录错误，不断优化
4. 灵活适应：市场变化时调整策略
5. 耐心等待：好机会需要等待
```
