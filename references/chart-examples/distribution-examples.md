## 案例1: 特斯拉(TSLA) 2021年分布期

### 📊 图表描述（2021年11月 - 2022年4月）

```
价格走势（周线）：
$420 ──────────────────────────────────
     │  PSY
     │  ╱
$410 │ ╱
     │╱
$400├──╱ CL
     │  ╲
$390 │   ╲
     │    ╲  AR
$380 │     ╲╱
     │      ╲
$370 │      ╲ ST
     │       ╲
$360 │        ╲ Upthrust
     │         ╲╲
$350 │          ╲╲
     │           ╲
$340 │            ╲ SOW
     │             ╲
$330 │              ╲
     │               ╲
$320 ─────────────────────────────────
```

### 🎯 威科夫事件标注

**Phase A - 停止上涨**：
- **PSY**: 11月第1周，$415附近，初步供应
- **CL**: 11月第4周，$410高点，成交量4.2倍（买入狂热）
- **AR**: 12月第1周，回调至$380，成交量2.1倍
- **ST**: 12月第2-3周，反弹至$395，成交量1.3倍

**Phase B - 派发**：
- 横盘整理8周（$380-$420区间）
- 成交量逐渐萎缩至0.7倍
- 出现3次ST，每次成交量递减
- 价格波动收窄

**Phase C - 假突破**：
- **Upthrust**: 2月第2周突破$420至$425
- 成交量2.8倍（吸引散户）
- 2天内回落至$410以下
- Upthrust日收盘价远离最高点（上影线长）

**Phase D - 下跌开始**：
- **SOW**: 3月第3周跌破$380至$365，成交量2.6倍
- **LPSY**: 3月第4-4月第1周反弹至$378，成交量1.1倍
- 收盘价接近当日低点

**Phase E - 下跌**：
- 12周内跌至$250
- 成交量支持下跌

### ✅ 做空信号

**最佳入场点**：
- **LPSY入场**: $375
- **止损**: $430（above Upthrust）
- **目标**: $315（因果测算：$420-$380=$40，$380-$40=$340）

**实际结果**：
- 入场后12周跌至$250
- 收益33%（做空）
- 风险回报比：($375-$250)/($430-$375) = 2.3:1

### 💡 经验总结

1. **Upthrust收盘位置是关键**：当日收盘价远离最高点=假突破
2. **SOW必须放量**：2.6倍确认
3. **LPSY成交量缩小**：1.1倍确认SOW有效
4. **新能源板块集体见顶**：板块共振很重要

## 总结：分布期交易要点

### ✅ 确认信号

1. **PSY, CL, AR, ST序列完整**
2. **Upthrust在1-3天内回落**
3. **SOW放量突破（>1.5倍）**
4. **LPSY缩量反弹**
5. **相对强度弱于大盘**

### ⚠️ 警示信号

1. **AR超过PSY**（可能失败）
2. **成交量没有萎缩**
3. **Upthrust超过3天未回落**
4. **SOW无量或失败**
5. **突破Upthrust高点**

### 💡 实战建议

1. **等待Phase D确认后再做空**
2. **LPSY是最佳入场点**
3. **止损设在Upthrust上方**
4. **因果测算目标**
5. **关注板块和基本面**
6. **不要强求每个顶部都是分布**

### ⚠️ 特别注意

**分布失败的特征**：
- Upthrust后继续上涨
- AR超过PSY
- 成交量没有萎缩
- 基本面利好

**应对**：
- 立即止损
- 不要加仓
- 重新评估
- 考虑反转做多
