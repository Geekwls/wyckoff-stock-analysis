# Spring和Upthrust专题案例集

## 案例说明

本文档专注于威科夫理论中最关键的两种形态：Spring（震仓）和Upthrust（假突破）。

包含10个真实案例，深入分析：
- ✅ 真实Spring的5个特征
- ❌ 假Spring的5个警告
- ✅ 真实Upthrust的5个特征
- ❌ 假Upthrust的5个警告


### 🎯 Spring的5个关键特征

**1. 位置正确**：
- 在Phase C（震荡末期）
- 已经有PS, CL, AR, ST序列
- 横盘已6周以上

**2. 跌破时间短**：
- Day 1: 跌破$140至$135
- Day 2: 继续在$136徘徊
- Day 3: 收回$145以上 ✓

**3. 成交量配合**：
- 跌破日: 2.8倍（散户恐慌）
- 收回日: 3.5倍（主力承接）← 最重要！

**4. 收回位置**：
- 收回至$145（AR支撑上方）
- 3天内完成
- 收回日收盘接近最高点

**5. 后续确认**：
- 收回后不再测试$140
- 2周后SOS突破$165
- Phase E顺利开始

### ✅ 交易信号

**入场策略1（激进的3天后）**：
- 入场：$146（Spring收回确认后）
- 止损：$133（below Spring低点）
- 目标：$175（因果测算）

**入场策略2（保守的LPS）**：
- 等待SOS: $168
- 等待LPS: $162
- 入场：$162
- 止损：$133
- 目标：$185

**实际结果**：
- 8周后涨至$200
- 策略1收益: ($200-$146)/$146 = 37%
- 策略2收益: ($200-$162)/$162 = 23%

### 💡 关键教训

1. **成交量在收回日放大是关键**：3.5倍 > 2.8倍
2. **3天规则**：3天内收回=真Spring，>3天=真下跌
3. **收回至AR上方**：$145 > AR起点
4. **Spring低点不能被再次测试**：如果再次跌破要止损

### ❌ 假Spring的5个警告信号

**1. 位置不对**：
- 虽有PS, AR
- 但CL不明确
- Phase B可能未完成

**2. 跌破时间长**：
- Day 1: 跌破$400
- Day 3: 仍在$385
- Day 5: 跌至$370 ✗ (超过3天)

**3. 成交量不配合**：
- 跌破日: 2.5倍
- Day 2-3: 逐渐萎缩
- Day 3: 仅1.2倍 ✗ (应该放大)

**4. 收回无力**：
- 3天内未收回$400
- Day 4尝试收至$395
- Day 5继续下跌

**5. 后续失败**：
- 继续下跌至$330
- 没有在$400附近形成支撑
- 证明是真正下跌

### ⚠️ 应对策略

**识别假Spring的关键时刻**：
1. **Day 1收盘**：如果收盘远离支撑位，警惕
2. **Day 2收盘**：如果仍在支撑下方3%，减仓/止损
3. **Day 3收盘**：如果仍未收回，确认失败，立即止损

**如果是LPS入场后的假Spring**：
- 立即止损
- 不要加仓摊平
- 等待下次机会

- 蓝筹股机构控盘
- 散户筹码少
- 跌破时散户恐慌割肉（量不大）
- 机构低位承接（量不大但有效）

## 第二部分：Upthrust（假突破）案例

### 案例6: 特斯拉(TSLA) 2021年经典Upthrust

### 📊 图表描述（2021年11月）

```
价格走势（日线）：
$430 ──────────────────────────────────
     │ CL
     │ ╲
$425 │  ╲
     │   ╲
$420 │    ╲
     │     ╲
$415 │      ╲ AR
     │       ╲╱
$410 │        ╲
     │         ╲
$405 │          ╲
     │           ╲
$400 │            ╲
     │             ╲ Upthrust
$395 │              ╲╲ ← 突破$430至$435
     │               ╲ ← Day 2回落至$420
$390 │                ╲
     │                 ╲
$385 │                  ╲
     │                   ╲ SOW
$380 │                    ╲
     │
$375┴──────────────────────────────────

成交量：
CL日:  ██████████ (4.2倍)
AR日:  ████████ (2.1倍)
Upthrust日: ██████████ (3.8倍) ← 吸引散户
回落日: ██████████ (3.2倍) ← 主力出货
```

### 🎯 Upthrust的5个关键特征

**1. 位置正确**：
- 在Phase C（分布末期）
- CL、AR、ST已发生
- 横盘已8周以上

**2. 突破时间短**：
- Day 1: 突破$430至$435
- Day 2: 回落至$420以下
- 3天内确认失败

**3. 成交量陷阱**：
- 突破日: 3.8倍（吸引散户追涨）
- 回落日: 3.2倍（主力趁机出货）

**4. 收盘位置**：
- 突破日收盘$432（远离最高$438）
- 上影线很长（典型诱多）

**5. 后续确认**：
- 回落后不再测试$430
- 2周后SOW跌破$390
- Phase E顺利开始

### ✅ 做空信号

**入场策略1（Upthrust确认后）**：
- 确认日：Day 2收盘跌破$425
- 入场：$423
- 止损：$445（above Upthrust）
- 目标：$390（因果测算）

**入场策略2（保守的LPSY）**：
- 等待SOW: $385
- 等待LPSY: $395
- 入场：$395
- 止损：$445
- 目标：$350

**实际结果**：
- 12周后跌至$250
- 策略1收益: ($423-$250)/$423 = 41%
- 策略2收益: ($395-$250)/$395 = 37%

### 💡 关键教训

1. **突破日收盘位置最重要**：远离高点=陷阱
2. **上影线长是警告**
3. **3天规则**：3天内回落=真Upthrust
4. **成交量是诱饵**：高量吸引散户
5. **Upthrust高点不能被再次测试**

## 第三部分：Spring和Upthrust对比总结

### 📊 对比表格

| 特征 | Spring（多） | Upthrust（空） |
|------|-------------|---------------|
| **位置** | 积累期Phase C | 分布期Phase C |
| **方向** | 向下假突破 | 向上假突破 |
| **目的** | 清除弱者 | 吸引追涨者 |
| **确认** | 1-3天内收回支撑 | 1-3天内跌破阻力 |
| **成交量** | 收回日放大 | 落下日放大 |
| **入场** | LPS（收回后回调） | LPSY（回落后反弹） |
| **止损** | below Spring低点 | above Upthrust高点 |

### ✅ 真假识别要点

**真Spring**：
- ✅ 1-3天内收回
- ✅ 收回日成交量放大
- ✅ 收回至AR上方
- ✅ Spring低点不再被测试
- ✅ 后续有SOS确认

**假Spring**：
- ❌ 3天以上未收回
- ❌ 成交量持续萎缩
- ❌ 收回无力
- ❌ Spring低点再次被跌破
- ❌ 后续创新低

**真Upthrust**：
- ✅ 1-3天内回落
- ✅ 落下日成交量放大
- ✅ 落下至AR下方
- ✅ Upthrust高点不再被测试
- ✅ 后续有SOW确认

**假Upthrust**：
- ❌ 3天以上未回落
- ❌ 成交量持续放大
- ❌ 收盘接近最高点
- ❌ Upthrust高点被突破
- ❌ 后续创新高

### 💡 实战建议

1. **永远等待确认**：不要在突破当日就入场
2. **3天规则是铁律**：超过3天=失败
3. **成交量确认最重要**：必须有配合的成交量
4. **止损必须严格执行**：假Spring/Upthrust要立即止损
5. **多重形态要耐心**：可能第2、3个才是真的
6. **结合整体环境**：大盘和板块配合
