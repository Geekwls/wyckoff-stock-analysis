## 案例1: 网易(NTES) 2022年积累期失败

### 📊 图表描述（2022年3月 - 6月）

```
失败的积累：
$130 ──────────────────────────────────
     │  PS
     │  ╱
$125 │ ╱
     │╱
$120├──╱ CL
     │  ╲
$115 │   ╲
     │    ╲ AR
$110 │     ╲╱ ← AR很弱，只到$115
     │      ╲
$105 │       ╲ ST ← 跌破PS低点$120
     │        ╲
$100 │         ╲ ← 没有Spring
      │          ╲
 $95 │           ╲ ← 继续下跌
      │            ╲
 $90 │             ╲
      │
 $85┴──────────────────────────────────

成交量：
CL日: ██████ (2.1倍)
AR日: ████ (1.2倍) ← 太弱！
ST日: ██████ (1.8倍)
后续: 持续放量下跌
```

### ❌ 失败的5个信号

**1. AR太弱**：
- AR只到$115（低于PS的$120）
- AR无法超过PS = 弱势
- 说明买盘不足

**2. ST跌破PS**：
- ST跌至$105（低于PS的$120）
- 供应未被吸收
- 需求不足

**3. 没有Spring**：
- 价格一路下跌
- 没有震仓动作
- 说明不是积累期

**4. 成交量不萎缩**：
- AR成交量只有1.2倍
- ST成交量1.8倍
- 后续持续放量下跌

**5. 宏观环境恶化**：
- 中概股监管压力
- 美联储加息
- 整体科技股下跌

### ⚠️ 识别要点

**积累期失败的早期信号**：
1. AR无法超过PS
2. ST跌破PS低点
3. 成交量没有萎缩
4. 没有3-4周以上横盘
5. 持续创新低

**应对策略**：
- 不要假设是积累期
- 等待明确的SOS
- 或等待Spring确认
- 严格止损

## 案例2: Meta(FB) 2018年分布期失败

### 📊 图表描述（2018年7月 - 10月）

```
失败的分布：
$220 ──────────────────────────────────
     │  PSY
     │  ╱
$210 │ ╱
     │╱
$200├──╱ CL
     │  ╲
$190 │   ╲
     │    ╲  AR
$180 │     ╲╱ ← AR很强，到$205
     │      ╲
$170 │       ╲ ST
     │        ╲
$160 │         ╲ Upthrust
     │          ╲╲ ← 突破$220至$225
     │           ╲ ← Day 3仍在$220
$150 │            ╲╲ ← Day 5突破$230
     │             ╲╲ ← 继续上涨
$140 │              ╲
     │
$130┴──────────────────────────────────
```

### ❌ 失败的5个信号

**1. AR超过PSY**：
- AR到$205 > PSY的$210（接近）
- 虽然未超过，但很强势
- 说明需求仍强

**2. Upthrust持续**：
- Day 3仍在$220
- Day 5突破$230
- 超过3天规则

**3. 成交量持续放大**：
- Upthrust日3.5倍
- Day 3仍有2.8倍
- 买盘真实

**4. 后续创新高**：
- 突破$230
- 继续上涨至$250
- 证明是真正上涨

**5. 基本面配合**：
- 业绩超预期
- 用户增长强劲
- 整体市场向好

### ⚠️ 识别要点

**分布期失败的早期信号**：
1. AR超过或接近PSY
2. Upthrust超过3天未回落
3. 成交量持续放大
4. 突破Upthrust高点
5. 基本面利好

**应对策略**：
- Upthrust确认失败立即止损
- 不要加仓做空
- 考虑反转做多
- 重新评估趋势

## 威科夫形态失败总结

### ❌ 积累期失败的5个信号

1. **AR弱于PS**：AR无法超过PS
2. **ST跌破PS**：Secondary Test跌破Preliminary Support
3. **成交量不萎缩**：持续放量
4. **没有Spring**：或Spring失败
5. **SOS失败**：Sign of Strength无法突破

### ❌ 分布期失败的5个信号

1. **AR强于PSY**：AR超过或接近PSY
2. **Upthrust持续**：超过3天未回落
3. **成交量持续放大**：买盘真实
4. **SOW失败**：Sign of Weakness无法跌破
5. **突破高点**：突破Upthrust或CL高点

### ⚠️ 失败的早期识别

**第1天（当日收盘）**：
- Spring: 收盘远离支撑位
- Upthrust: 收盘接近最高点

**第2天（确认）**：
- Spring: 仍在支撑下方3%
- Upthrust: 仍在阻力上方

**第3天（铁律）**：
- 超过3天=失败，立即止损

### 💡 风险管理

**入场前**：
1. 确认形态完整
2. 多时间框架分析
3. 风险回报比>1.5:1

**入场中**：
1. 严格执行止损
2. 不加仓摊平
3. 密切观察3天规则

**失败后**：
1. 立即止损
2. 重新评估
3. 等待下次机会
4. 总结经验教训

### 🎯 实战建议

1. **不要假设每个横盘都是积累/分布**
2. **等待确认，不要预判**
3. **3天规则是铁律**
4. **止损比盈利更重要**
5. **基本面可以改变技术形态**
6. **保持灵活，不要固执**
